# Contributing to PDF-to-MD-to-AudioBook

Thank you for your interest in contributing! We welcome bug reports, feature requests, and code contributions.

## Reporting Bugs

If you encounter a bug, please open an issue with the following details:
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Device/Emulator information (Model, Android Version).
- Logcat output (if available).

## Feature Requests

We are open to new ideas! Please check the [Product Requirements](docs/prd.md) and [Future Scope](docs/prd.md#future-scope) first. If your idea fits, open an issue describing:
- The problem you want to solve.
- Your proposed solution.

## Development Setup

1. Follow the [Installation](README.md#installation) instructions in the README.
2. Ensure you are using the official Kotlin coding conventions.

## Pull Request Process

1. Fork the repository and create a new branch for your feature or fix.
2. Write clean, documented code.
3. Ensure the app builds and runs without errors.
4. Submit a Pull Request with a clear description of your changes.
5. Link any relevant issues in your PR description.

## Code Style

- We follow the standard [Kotlin Coding Conventions](https://kotlinlang.org/docs/coding-conventions.html).
- Use `ktlint` or Android Studio's formatting tools before submitting.

## Testing

- Run unit tests (if applicable) using `./gradlew test`.
- Manually test the changes on an emulator or physical device.

Thank you for helping improve this project!
