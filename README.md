# PDF-to-MD-to-AudioBook
 
Convert PDFs into clean Markdown and audiobook audio with aligned chunk
timestamps. This repo is in early setup and focuses on:
 
- PDF to Markdown extraction and cleanup
- Image extraction and manifests
- Markdown to audiobook generation with chunk alignment
- A mobile playback app with single-button control
- DevOps foundations (auto-deploy, logging, feedback)
- Agent-accessible testing and orchestration
